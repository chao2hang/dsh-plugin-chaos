# `@deepseek-ai/dsh-plugin-chaos-models`

[English](README.md) | 中文

为通过 `llm-pi-ai` 提供的非官方模型提供输入框侧的能力配置。

## 行为

插件在已有模型选择器的菜单中增加“**模型能力设置**”。它读取当前会话模型，并向该模型的 `llm-pi-ai` 配置写入最小补丁。设置描述符会在客户端启动时预热、在各次打开间共享，并在设置提交后失效，因此重新打开对话框无需再次等待完整设置读取。可设置：

- 上下文窗口；
- 默认最大输出 token；
- 图片多模态输入；以及
- 可选择的思考等级。

保存自定义模型会更新其 `models` 条目；保存目录模型会写入 `modelOverrides.<model-id>`。两者均由 `llm-pi-ai` 校验并实时应用，下一次模型解析会重建适配器目录。未选择任何思考等级时写入 `reasoningEfforts: false`；选择 `off` 时使用 pi-ai 的无参数 `off` 值，其他等级使用各自的线值。

官方适配器及不属于 `llm-pi-ai` 的提供方不会被修改，界面会明确说明其不能使用此配置。

## 组合

`chaos-bundle/cordis.patch.yml` 以 `chaos-models` 挂载此包。客户端等待 `conversation.input.right` 槽位以挂载对话框，而原有的 `conversation.input.model` 菜单提供唯一的可见入口。移除此插件会同时移除菜单项和对话框。

## 模型体验

无。能力对话框在浏览器中渲染，选择通过 pi-ai 设置路由持久化；这里没有任何内容进入模型请求。

#### KV Cache 影响

无；该包既不组装也不发送提供方请求。

## 已知限制与延后工作

- 对话框无法探测提供方能力；仅填写端点确实支持的值。
- 当前模型不在 pi-ai 路由配置中时可写入覆盖，但该路由必须已经在 `llm-pi-ai` 中配置。

**运行时不变式：** 不发布伴生入口。包只拥有一个带键的 `conversation.input.right` slot 注册，其渲染的对话框状态每次渲染都从 pi-ai 设置快照派生——自身不持有跨事件的可变状态。
