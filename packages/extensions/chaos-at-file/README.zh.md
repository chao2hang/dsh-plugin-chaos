# `@deepseek-ai/dsh-plugin-chaos-at-file`

[English](README.md) | 中文

为 DeepSeek Harness Web 输入框提供 Codex 风格的工作区 `@path` 引用。该插件负责自己的选择器、引用标签、过滤设置以及模型可见的存在性标记。Chaos bundle 启用它时会关闭 Web bundle 内置的 `ui-reference` 来源，因此输入框只保留一个文件选择器。

## 行为

在输入框输入 `@` 后接文件名或路径，可搜索当前会话的工作区。选择器只索引文件和目录，不读取文件字节。选择文件会插入可删除的引用标签；选择目录会保持补全打开，按 **ArrowRight** 可进入当前高亮目录。

模型步骤开始前，插件会确认每个引用的相对路径仍位于会话工作区内且确实存在。每个有效路径会追加一条用户消息，例如：

`<workspace-reference path="docs/spec.pdf" kind="file" />`

该标记不包含文件内容或目录列表。模型只能通过会话中可用的工具读取引用路径。无效、缺失、绝对或逃逸工作区的路径保持为普通用户文本。

## 设置

**设置 → 文件引用** 管理实时 `chaos-at-file` 命名空间：

- 启用或隐藏选择器、引用栏和 pre-step 标记；
- 默认忽略粘贴进来的 `@path`；以及
- 添加全局或工作区专用的精确文件名和正则表达式过滤规则。

索引始终排除常见元数据、依赖、缓存和构建输出目录。插件配置可修改条目上限与目录排除列表：

```yaml
- id: chaos-at-file
  name: '@deepseek-ai/dsh-plugin-chaos-at-file'
  config:
    maxIndexedFiles: 5000
    ignoreDirs: ['.git', 'node_modules', 'dist']
```

过滤规则变化会在下一次查询前使浏览器缓存失效。`ignoreDirs` 必须是非空目录名，`maxIndexedFiles` 必须是正安全整数。

## 移动端布局

屏幕宽度不超过 560px 时，选择器保持在视口内；路径标签使用输入框的完整宽度；删除、过滤和设置控件使用 36–44px 的触控目标。长文件名会在选择器行中换行；引用标签仅截断显示文本，不截断插入路径。

## 模型体验

### 工作区引用

#### 模型可见内容

插件不增加固定提示词。有效的用户 `@path` 会在下一模型步骤添加一个简短的 `workspace-reference` 标记，原始 `@path` 仍保留在用户文本中。

#### Token 影响

可变：每个已声明用户消息中的不同有效引用添加一个短标记。选择器索引、设置、标签和过滤候选不会增加请求 token。

#### KV Cache 影响

不会修改稳定前缀。引用标记变化只影响该步骤用户消息的后缀。

## 已知限制与延后工作

- Host 文件系统索引和会话有效的 `read` 工具必须访问同一工作区命名空间；远程或虚拟文件系统部署需要匹配的 provider。
- 有界索引在超过 `maxIndexedFiles` 后可能遗漏条目；无权访问和损坏链接的目标会被省略。
- 默认排除目录列表只在插件激活时读取。如需修改，请在 profile 配置中设置并重启 Host。

**运行时不变式：** 不发布伴生入口。每次索引应答都从实时文件系统按调用派生，设置区块归 settings 提供方所有，前置步骤标记追加的是 agent loop 自己记录的消息——包内不持有关联两条事件流的可变状态，注册处置由 HMR 安全 spec 证明。
