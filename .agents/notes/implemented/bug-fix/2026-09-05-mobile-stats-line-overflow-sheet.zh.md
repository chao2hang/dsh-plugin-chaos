# Agent Note: 会话统计行退出手机工作区，移入省略号弹窗

Status: implemented

[English](2026-09-05-mobile-stats-line-overflow-sheet.md) | 中文

## 问题

手机上，会话统计行（轮数 / 步数、LLM 与工具耗时、TTFT 与解码速度、缓存命中、token 合计）挤在输入框下方，和操作行争夺手机上仅有的版面。移动端样式表本来就会隐藏 `[data-stats-line]`，overlay 也本来就会把该行渲染出的文本镜像进省略号弹窗的「会话统计」一节，但 dsh 0.1.3-alpha.1 的 `StatsLine` 从未输出 `data-stats-line` 属性，隐藏规则匹配不到、镜像读到的是空：每个手机会话底部都还挂着这行统计。

## 决策

`StatsLineContent` 在它带尺寸测量的行元素上输出 `data-stats-line`；该元素本来就携带完整格式化文本。行在隐藏状态下保持挂载：它继续拥有 `sessionStats` / `tokenUsage` 投影读取、窗口回退折值和语言包格式化，overlay 里现成的观察器只跟随其渲染文本。移动端代码零改动，两个休眠的消费者被锚点激活。

## 曾考虑的替代方案

**在弹窗内重新计算这些数字。** 弹窗渲染在 overlay 的全局作用域槽位，没有投影套件；在那里复制投影读取、回退折值和每一组文案，等于在被遮挡的那行旁边再造一份格式化器。

**按 CSS module 类名或 DOM 位置选行。** 类名按构建加哈希，行在停靠区里的位置随停靠区组成变化，两种选择器都会静默失效。

## 后果

手机工作区不再显示统计行，省略号弹窗在「上下文占用」一节下方以「会话统计」一节展示完整格式化行。chat 统计规格固定所输出的锚点及其文本等于完整行；mobile.css 规格固定隐藏规则；overlay 规格经由同一锚点覆盖弹窗小节。
