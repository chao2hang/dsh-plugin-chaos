# Agent Note: 用于工作目录审查的停靠式桌面工作台

Status: implemented

[English](2026-08-20-desktop-companion-panel.md) | 中文

## 问题

桌面 Web 用户需要一个可与当前对话并列存在的工作目录界面。参考交互为可调整大小的右侧工作台与可选底部停靠区保留主内容空间，并将工作目录导航、源码审查、命令输出、浏览器工作和任务状态集中为可独立选择的视图。

## 决策

`@deepseek-ai/dsh-plugin-chaos-desktop-panel` 通过 ui-layout 的增量 `shell.overlay` 插槽挂载工作台。右上角控制组可打开独立调整大小的右侧面板和底部停靠区；其占用的屏幕区域通过根 CSS 变量反映。两个停靠区都在按会话保存的浏览器存储中维护各自已选择和已打开的标签。右侧停靠区可分割为两个带有独立标签的窗格，并可拖动分隔条调整大小。

工作台提供可展开且可搜索的服务端根目录文件树、文本上传、带 HTML sandbox 模式和下载的可编辑文本预览、Git 状态/差异/历史审查、按会话和可见窗格隔离、带受限回放和重连宽限期的常驻 Bash PTY、带导航历史的隔离浏览器、显示生命周期、生产者、时间与详情的当前会话任务和消息编辑器。工作目录路由要求同源请求；文件读写使用带路径包含检查的 `/api/chaos-desktop/file` 路由。Git 修改对位于工作目录内的结构化路径执行暂存、取消暂存、丢弃、提交和本地分支切换。Web bundle 通过 `chaos-desktop-panel` 条目挂载该插件。

浏览器终端在 subprocess PTY primitive 之上拥有独立的 WebSocket 注册表。它在服务端推导选中会话的 cwd、保留受限回放、串行化写入，并按会话和工作台窗格为每个 PTY 建立键，要求 loopback same-authority upgrade，除非请求已认证，并在重连宽限期或插件 teardown 后结束 shell。

## 曾考虑的替代方案

- **窄小的覆盖式侧边栏**：否决，因为它不占用屏幕宽度，也无法提供参考交互的工作台层级。
- **替换 ui-layout 根框架**：否决，因为增量 `shell.overlay` 插槽保留已有布局所有权与移动端行为。
- **从浏览器调用 Agent 所有的 PTY 服务**：否决，因为它的所有权、生命周期和仅轮询 API 不会授权或传输浏览器交互。

## 后果

工作台独立于对话导航，随时可以隐藏。用户可以检查和编辑受限的工作目录文件、审查 Git 改动，并同时显示两个右侧视图。

宿主路由将选中的活动会话解析到其不可变的 `cwd`，仅在没有工作目录时使用 Web 服务进程目录。终端 escape-sequence emulator、连接后的终端 resize、Git 历史修改和插件定义的标签注册仍待实现。
