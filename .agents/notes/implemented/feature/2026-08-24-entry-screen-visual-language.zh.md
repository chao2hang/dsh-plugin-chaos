# Agent Note: 受保护入口与启动页使用中文印章视觉语言

Status: implemented

[English](2026-08-24-entry-screen-visual-language.md) | 中文

## 问题

受保护的登录页和无框架 Web 启动页是访客最先看到的产品状态。通用英文文案、蓝色强调色和未设计的加载提示，使这些状态与中文 Web 界面彼此割裂。

## 决策

服务端渲染的登录页和 `dsh-client-web` 启动页共用暖墨底色、纸白文字、朱砂强调色、宋体风格中文排版和「启」印章。入口的产品文案使用中文。启动页在主题插件之前渲染，因此自行拥有早期启动所需的颜色与字体；`body[data-ds-dark-theme]` 选择深色墨面调色板，默认使用纸本感浅色调色板。加载进度环和完整失败诊断保持可用。失败报告使用中文标题，并原样保留 Loader 标识符和报告文本。

## 曾考虑的替代方案

- **使用常规 UI 主题 token**：可与已加载的应用对齐，但启动页必须在该 token 样式表或其插件加载失败时仍然可用。
- **以渐变和发光效果作为视觉标识**：这会传达通用的 AI 产品风格，不能满足入口流程需要的克制编辑感。

## 后果

- 应用挂载前，受保护状态与启动状态共享可识别的视觉语言。
- 启动页保留一份小型自包含样式表，有意复制早期启动需要的颜色与字体选择。
- 应用完成启动后，仍可使用独立选择的主题和组件 token。
- 启动页测试固定中文加载与失败状态、ARIA status/alert 语义、进度环和持久化深色主题背景。
